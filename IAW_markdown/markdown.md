# Resum de Markdown

Aquest document és un resum de la sintaxi que he utilitzat.

## Títols
Es fan amb `#`. Com més `#`, més petit és el títol.

## Format
- `**text**` → **negreta**
- `*text*` → *cursiva*
- `~~text~~` → ~~ratllat~~

## Llistes
- Amb `-` es fa una llista normal
- Amb `1.` es fa una llista numerada

## Enllaços i imatges
- Enllaç: `[text](url)`
- Imatge: `![text](ruta)`

## Codi
Amb una cometa inclinada `` ` `` per a codi curt, i amb tres per a blocs.
