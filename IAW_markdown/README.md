# Exercici 2 - Markdown

Hola, sóc **David** i aquest és el meu primer document en *Markdown*.

## Què és Markdown
Markdown és un llenguatge de marques per a donar format als textos de manera fàcil.

> Es pot convertir a HTML molt fàcilment.

## Llistes

Coses que he fet:
1. Crear la carpeta
2. Crear el README
3. Afegir una imatge

Elements de Markdown:
- Títols
- Negreta i cursiva
- Imatges
- Enllaços

## Codi

Per a veure l'estat del repositori faig `git status`.

```
git add .
git commit -m "exercici 2"
git push
```
